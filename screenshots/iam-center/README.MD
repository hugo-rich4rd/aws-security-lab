
## IAM Identity Center

### Atividades realizadas

1. Habilitação do IAM Identity Center
2. Criação de usuários
3. Criação de grupos
4. Configuração de Permission Sets
5. Atribuição de acesso a contas AWS
6. Validação de login pelo Access Portal

### Conceitos praticados

- Single Sign-On (SSO)
- Centralized Identity Management
- Permission Sets
- Group-based Access Control
- Multi-Account Access Management
